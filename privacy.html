Privacy policy

This document covers two separate things — this website first, then the Avro Keyboard Community Edition desktop app. In both cases it says what actually happens.

In short

In short — no account, no cookies, no analytics, no ads, no tracking. We neither ask you for personal information nor receive any. The desktop app sends no telemetry and never stores the text you type.

The only network traffic is from your own browser to GitHub's public API (for blog posts, GitHub's raw.githubusercontent.com), and — in the app — from GitHub Releases, at your own request, when you download resources or an update.

⓵ What happens on this website

Hosting

The site is a static site hosted on GitHub Pages. We run no server of our own, keep no database and store no logs. But as with any web hosting, GitHub may record a visitor's IP address, browser/device information and the time of the request in its own system logs. Those logs are under GitHub's control, not ours — see GitHub's privacy statement for the details.

API calls for the live data

To load the counters, release cards, changelog and blog posts, your browser sends requests straight to api.github.com; blog post files come from GitHub's raw.githubusercontent.com — both are GitHub services. What that means:

  • Your IP address reaches GitHub — exactly as it already did just by loading this site from GitHub Pages.
  • We ask only for public repository and release data — who you are, or any identity of yours, is never sent anywhere.
  • No API token, login or cookie is used; the request is entirely anonymous.
  • Nothing is profiled — this data is not stored anywhere on our side, because there is no server of ours to store it on.

⓶ What your browser stores

The site uses only localStorage — no cookies at all. These keys live in your browser and are only used to make your next visit work better:

Key What it holds Why
avro-theme Only light or dark To keep the theme you chose across later page loads
avro-gh-v1 A cache of public data fetched from the GitHub API (repository stats, release list) and when it was fetched So the same data is not fetched again and again, sparing the API's hourly limit
avro-snap-v2 A snapshot of the last public data received (repository stats, releases, the official baseline, blog posts) and when it was taken So the real numbers can still be shown if the GitHub API later stops responding — newer data than the snapshot bundled with the site
avro-lang The language you chose — en or bn To show later page loads in the language you picked

There is no personal information in this storage — it is the same public data anybody can see on GitHub. The cache normally expires by itself after about ten minutes, and the snapshot is refreshed with new data on your next visit.

⓷ What we do not do

  • No analytics — no Google Analytics or anything like it.
  • No tracking and no fingerprinting — no pixels, beacons or scripts.
  • No advertising, and no ad network either.
  • No forms and no accounts — no sign-up, newsletter or email collection.
  • No third parties — no CDN, font server or social button is loaded from outside; even the fonts come from inside this site.
  • No selling or sharing of data — because there is no data of yours here to sell.

⓹ The desktop app: where the data lives

The app keeps all of its data on your own computer. Where depends on which edition you are running:

Edition Settings Data (database, mappings, layouts, skins, logs)
Standard (installed) HKEY_CURRENT_USER\Software\OmicronLab\Avro Keyboard %ProgramData%\Avro Keyboard\
Portable Settings.xml beside the exe In the folder that contains Avro Keyboard.exe

Both editions write three registry entries — saying "no registry changes at all" would not be accurate:

  • HKCU\Control Panel\Desktop\LowLevelHooksTimeout (5000 ms) — so that Windows does not silently drop the keyboard hook if another app stalls for a moment.
  • Two IE font values (IEFixedFontName, IEPropFontName) while the portable Siyam Rupali font is registered — the previous values are kept in _Prev entries and restored when the font is removed.

The portable edition installs and registers nothing system-wide; the folder can be moved or deleted at any time.

⓺ AvroStartup.log — what is written, and what is not

So that a problem at startup does not end in a silent exit, the app writes a diagnostic log. It contains: the startup steps, which edition is running, the paths to the exe and the data folder, whether the folder is writable, the database file's size and modification time, the Windows build number, and — if a step fails — that exception's class and message.

This log never contains anything you typed. No keystroke, no word and no sentence is ever recorded in it — at runtime the most that is written is an exception class. The debug log (Log()) writes to a debugger only, never to a file.

The log sits beside the data files and rotates into AvroStartup.log.old once it passes 256 KB. If the data folder cannot be written it falls back to %LOCALAPPDATA%\AvroKeyboard\, then to %TEMP%\AvroKeyboard\; if nowhere is writable the log is quietly dropped — startup never depends on the log.

⓻ When the app uses the network

The app sends nothing anywhere on its own. The network is used only when you ask it to download something:

  • Downloading layout, skin or ANSI mapping packs from “Download Resources” in the tray menu.
  • Downloading a new build through the in-app auto-update.

Both requests go to GitHub, and every downloaded file is verified with SHA-256 before it installs. No crash reports, usage statistics or personal identifiers are sent anywhere.

⓼ Removing all of it

To remove every trace of the app from your machine:

  • Portable: delete the folder, then delete the HKCU\Control Panel\Desktop\LowLevelHooksTimeout entry.
  • Standard: uninstall, then delete the %ProgramData%\Avro Keyboard\ folder and the HKEY_CURRENT_USER\Software\OmicronLab\Avro Keyboard key.
  • Update folder: if you used auto-update, downloaded packages may be inside the data folder — removing the whole data folder takes those with it.
  • This website: delete the avro-gh-v1, avro-snap-v2, avro-lang and avro-theme keys from your browser settings, or clear this site's data.
  • Logs: AvroStartup.log and AvroStartup.log.old also live in the data folder — they go with it.
