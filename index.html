The official column comes from the release information published on OmicronLab.com and the archived upstream repository's metadata. Every claim in the Community Edition column traces back to this repository's Readme and the 6.0.2-beta release notes.

Engine

A new ANSI/Bijoy conversion engine

The single hardcoded mapping inside has been removed so every V1–V5 encoding is file-based. The engine is pre-warmed, switching versions allocates nothing, and the setting survives a cache restart.

Converter

Avro Text Converter is now inside the app

Open it from the tray menu or by pressing Ctrl+Alt+T. It converts both ways, Unicode ↔ ANSI, and the window no longer freezes on large text — the work runs in the background.

Resources

In-app “Download Resources”

Find and download layout, skin and ANSI mapping packs from inside the app. Every file is verified with SHA-256 before it installs, and it loads without a restart.

Updates

Auto-update straight from this GitHub repository

Picks the right file for the architecture you are running, verifies the download link live before offering it, hands portable builds the portable package, and keeps a beta channel toggle.

Reliability

Startup never fails silently

Bad settings, a locked registry, missing fonts or a corrupt Database.db3 used to close the app without ever showing a window. Every step is guarded now, with a visible report and AvroStartup.log.

UI

Interface and theming

An app-wide theme and palette system, a “Select ANSI Encoding” tray menu that stays in sync with every picker, layout-aware icons, and correct natural sorting like V1 → V5.

Packaging

Native 64/32-bit and genuinely portable

The official build was a single 32-bit installer; here you get an installer and a portable build, on both architectures. In the portable build the settings live in Settings.xml beside the exe, so you can run it from a USB stick and leave a clean machine behind.

Build

Built for community contribution

Builds with no third-party dependency in the latest free Delphi Community Edition (build-ce.bat). Contributions are welcome in both Delphi and the Qt converter — not just one of them.

Privacy

No tracking, no telemetry

The app sends no telemetry, and AvroStartup.log never contains the text you type. Use the portable folder without installing and nothing system-wide is registered at all.

What is still limited — better said plainly

  • This is an independent continuation. A separate continuation from Avro Keyboard's open-source code (MPL-2.0) — not affiliated with OmicronLab. The official site and the older versions are still at OmicronLab.com as before.
  • The binaries are not code-signed yet (the official 5.6.0 was), so Windows SmartScreen may show “More info → Run anyway”. Comparing the SHA-256 of the file you downloaded settles it.
  • The portable edition still writes three HKCU keys — LowLevelHooksTimeout (so Windows does not silently drop the keyboard hook) and two IE font values while the portable Siyam Rupali font is registered, which revert when the font is removed. Nothing system-wide is installed.
  • Some resources are not in the public repository. The proprietary ANSI encoding configuration, certain mapping files and the key material were kept private. So a build made from a clone of this repository cannot open the default-key .AvroEnco container — instead of a confusing decode error it says plainly that the secret is unavailable. That is the expected behaviour of a clone build.
  • This is a beta. If something behaves oddly, open an issue with your Windows version, which file you downloaded and the version shown in the About box.

What is inside

The things that make a difference in everyday typing

Every point is written down in the 6.0.2-beta release notes or in this repository's Readme.

Native 64- and 32-bit

Separate builds for both architectures. The 64-bit build is steadier on large documents and long sessions.

Genuinely portable

Settings sit beside the exe, inside the data folder. Run it from a USB stick, delete the folder when you are done.

A file-based ANSI engine

Every V1–V5 encoding loads from its own file — no hardcoded mapping is left.

Startup never fails silently

Every step is guarded, with a visible report and AvroStartup.log.

Downloads verified with SHA-256

Resources and updates alike only install once the file hash matches.

Grapheme-aware backspace

A compound character no longer breaks leaving a stray vowel sign behind — the whole grapheme goes at once.
